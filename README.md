# Invente une histoire de Noël

L'élève secoue la hotte du Père Noël 3 fois pour tirer un personnage, un cadre et une péripétie, puis invente son histoire sur iPad ou sur papier.

Ouvrir l'application : https://ludo1104-rp.github.io/histoire-noel/
